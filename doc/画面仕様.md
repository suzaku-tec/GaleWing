
# 画面仕様

## 1. 共通レイアウト

多くの画面は左側にナビゲーション、右側にコンテンツを配置する。画面上部のメニューアイコンでサイドバーを開閉でき、閉じるとコンテンツ領域が広がる。サイドバーにはフィード一覧、設定、サイト管理、カテゴリ、タスク実行などのリンクが並ぶ。積読、Podcast、ビュー設定、外部ニュース、RSS Bridge、統計、AI推薦、フィードカテゴリ、トレンド等は機能設定に応じて表示される。

## 2. フィード一覧

### 2.1 サイト・ビューの選択

- サイドバーの View Link からビューを選ぶと、ビューに含まれるサイトのフィードを表示する。
- Site List からサイトを選ぶと、そのサイトのフィードを表示する。All を選ぶと全サイトが対象になる。
- 現在選択中のサイト/ビューは強調表示される。サイト一覧には未読件数が表示される。

### 2.2 一覧表示とページ移動

- 標準レイアウトは記事タイトルと公開日時をグリッド表示する。タイトルは記事の Web ページを別タブで開く。
- ページサイズは一覧の上下にある入力欄から変更できる。先頭/前/次/末尾ボタン、またはページ番号入力で移動できる。上下のページ操作欄は同じ一覧状態を示す。
- `feed_rows` 設定値が初期ページサイズに使われる。
- カードレイアウトでは記事をカードとして表示する。カード内には画像、タイトル、公開日が表示され、カードを選ぶと記事を開く。ページ番号と Previous/Next で移動する。
- グリッド/カードの切り替えは画面上部のレイアウトタブから行う。

### 2.3 既読と記事操作

- タイトルをクリックすると記事を別タブで開き、一覧上の記事を既読表示にする。
- 一覧チェック操作は現在表示中のページの記事を既読にする。
- 既読ボタンは現在のサイト/ビューで表示される記事を一括既読にする。完了後、次のサイトへ進める場合は次サイトへ移動し、それ以外は画面を再読み込みする。
- 前/次ページへ移動する際、移動前に表示されている記事を既読にする。
- 翻訳タイトルがある記事は翻訳タイトルで表示される。タイトル読み上げボタンは一覧タイトルを順に音声再生する。

### 2.4 上部アクション

| 操作 | 挙動 |
|---|---|
| サイドバー | ナビゲーションの開閉 |
| `+` | サイト追加ダイアログを開く。URLを入力して確定すると登録を依頼し、ダイアログを閉じる |
| 更新 | 現在対象のフィードを更新し、一覧とサイト別未読件数を更新する。処理中は更新メッセージを表示する |
| チェック | 現在対象のフィードを一括既読 |
| 再生 | 表示中のタイトルを順番に読み上げる |
| 工具メニュー | OPML のインポート/エクスポート |
| リスト | 表示中ページの記事を既読にする |
| Markdown | 表示中ページの未読タイトルを Markdown 箇条書きとしてクリップボードへコピー |
| All Title MD | 全タイトルを Markdown 化する操作 |

### 2.5 キーボード操作

- `Ctrl+Alt+R`: 対象フィードを一括既読
- `Ctrl+Alt+C`: 表示中ページの記事を既読
- `Ctrl+Alt+T`: Markdown タイトル操作に割り当てられている

## 3. サイト管理

サイト管理画面にはタイトル、サイト URL、最終更新、操作列を持つ一覧が表示される。URL はリンクとして開ける。各サイトで `tags` を選ぶとサイトカテゴリ操作、`del` で削除、`icon` でアイコン更新を行う。`feed list` はフィード一覧へ戻り、`reload&update` はフィード更新を実行する。

## 4. カテゴリ

カテゴリ画面では登録済みカテゴリを表示する。追加ボタンからカテゴリ名と説明を入力して登録し、各カテゴリの削除操作で削除する。フィードカテゴリ画面ではカテゴリを選択して対象フィードを切り替える。

## 5. ビュー設定

ビュー設定画面では既存ビューを選択し、含めるサイトのチェック状態を編集できる。ビュー名を入力して `new` を押すと新規ビューとして保存する。既存ビューを選択して `Save` を押すと、そのビューの名前とサイト構成を更新する。保存後は画面を再読み込みする。ビュー名が空の場合は保存しない。

## 6. 設定・機能フラグ

設定画面では設定項目をグループごとに表示し、値を編集して `update` で保存する。機能フラグ画面では機能ごとの利用可否を管理する。ナビゲーション上の一部リンクは該当機能が有効な場合に限って表示される。

## 7. タスク実行

タスク画面では実行可能なタスクをセレクトボックスから選び、`実行` を押す。選択が空の場合は実行要求を送らない。画面上には共通のフィード操作ボタンも配置される。

## 8. 分析・情報画面

| 画面 | 主な表示・操作 |
|---|---|
| トレンド | 対象日を指定して検索し、キーワード別の記事数と前日比を表示する。キーワードを選ぶと関連フィードを表示し、summary 操作を行える |
| 統計ダッシュボード | 閲覧率やランキング等の集計を表示する |
| 統計 SQL | SQL 実行・統計 ID の操作を行う |
| フィード分析 | 対象フィードを表示し、タイトル読み上げ等の操作を行う |
| AI おすすめ | おすすめ記事のタイトルと元記事を表示する。元記事リンクは別タブで開き、既読ボタンでおすすめ項目を既読にする |
| ニュース要約 | 要約対象の記事をカード表示し、summary で要約内容を確認、削除操作で項目を削除する |
| Podcast | `+` で Podcast 追加、更新ボタンでエピソードを同期する |
| 積読 | 保存した記事を一覧表示する |
| 外部ニュース / RSS Bridge / YouTube | 各連携サービスの情報を表示し、画面に用意された検索・一覧操作を利用する |
| 循環 | 対象記事等を登録して循環表示する |

## 9. ダイアログ

サイト追加、Podcast 追加、OPML インポート、関連情報表示、更新メッセージなどはダイアログで表示する。フォームには確定/キャンセル操作があり、キャンセルまたは閉じるボタンでダイアログを閉じる。入力検証や失敗時の表示は各操作のルールに従う。
